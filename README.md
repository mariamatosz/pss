## Abrir no computador

Extraia o ZIP, abra a pasta pss-main no VS Code e use Open with Live Server no index.html. Com Python instalado, também é possível executar `python -m http.server 8000` nesta pasta e acessar http://localhost:8000. Abrir por duplo clique pode impedir a leitura dos arquivos JSON.

## Dados públicos e organização

A pesquisa FPA/Sesc aparece apenas no painel de experiências. O OuvidorSUS tem seção própria com série anual, tabela e downloads. A origem institucional é atribuída ao OuvidorSUS, com crédito à solicitação da autora. A resposta administrativa original ainda precisa ser anexada e conferida.

Perfil das vítimas inclui diferenças por raça/cor na pesquisa nacional Nascer no Brasil, com dados de 2011 a 2012 e publicação de 2017. Não há distribuição por renda ou escolaridade validada para este painel. O comparativo internacional apresenta reconhecimento institucional e normas selecionadas, sem equiparar leis e orientações nem calcular ranking de violência.
